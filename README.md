# CV Webseite – Laser Gedik

## Projektbeschreibung

Dies ist eine moderne CV- und Portfolio-Webseite im Rahmen der Modularbeit im Web Programming Basics.

Die Webseite dient als persönliches Online-CV und präsentiert:
- Profil
- Arbeitserfahrung
- Ausbildung
- Qualifikationen
- Kontaktinformationen

## Abgeschlossene Schritte

- GitHub Repository erstellt
- Projektstruktur erstellt
- HTML Grundstruktur aufgebaut
- CV Inhalte integriert
- Profilbild eingebunden
- Responsive CSS Layout erstellt
- Navigation und Sections umgesetzt

## Aktueller Stand

Die Webseite enthält aktuell:
- Startseite
- Profilbereich
- Qualifikationen
- Arbeitserfahrung
- Ausbildung
- Interessen
- Kontaktbereich
