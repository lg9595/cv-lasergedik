# CV Webseite – Laser Gedik

## Projektbeschreibung

Dies ist eine moderne CV- und Portfolio-Webseite im Rahmen der Modularbeit im Web Programming Basics.

Die Webseite dient als persönliches Online-CV und präsentiert:
- Profil
- Arbeitserfahrung
- Ausbildung
- Qualifikationen
- Kontaktinformationen

## Technologien

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Ziele

- Responsive Webseite
- Saubere HTML/CSS-Struktur
- Modernes Design
- Professioneller Entwicklungsprozess mit Git
